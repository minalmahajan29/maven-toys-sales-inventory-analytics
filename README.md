# 🧸 Maven Toys: Sales & Inventory Executive Analytics

An end-to-end data analytics project simulating a retail chain optimization strategy using Python, MySQL, and Power BI.

## 🚀 Project Overview
This project analyzes sales, product profitability, inventory costs, and regional store performance for Maven Toys. The goal is to identify profit drivers, holiday seasonal trends, and inventory bottlenecks to guide executive business decisions.

## 🛠️ Tech Stack & Tools
* **Python (Pandas)**: Data cleaning, missing value handling, date-time formatting, and data type mapping.
* **MySQL & SQLAlchemy**: Relational database schema design, foreign key constraints, and querying.
* **Power BI**: Interactive executive dashboard development, data modeling (star schema), and DAX measures.
